- Comprehensive TSDoc documentation for all public APIs

- GitHub Actions CI/CD pipeline

### Changed

- Updated TypeScript configuration with stricter checks
- Improved package.json scripts for better DX
- Enhanced README with testing and quality information

### Developer Experience

- Added `npm run validate` script to run all checks
- Added `npm test` for interactive test development
- Added `npm run test:ui` for visual test debugging
- Added `npm run lint:fix` for automatic code fixes
- Added `npm run format` for code formatting

## [1.0.0] - Initial Release

### Features

- Visual editor for creating Kubito characters
- Drag & drop asset management
- Real-time transformations (move, scale, rotate)
- Professional alignment tools
- Visual effects system (shadows, blur, filters)
- Layer management with z-index control
- Undo/redo history (up to 50 states)
- Export to SVG, PNG, JPEG
- Save/load projects as .kubito files
- Responsive design with mobile support
- Keyboard shortcuts for common actions
- Grid and snap-to-grid functionality
- Multiple color palettes
- Theme system (light/dark)
